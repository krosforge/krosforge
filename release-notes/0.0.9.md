# Krosforge 0.0.9

- Open the character's Characteristics panel with **C**. The panel now receives all six primary attributes.
- Preview the battle arena with **L** or **Combat Map** from the right-click menu, including on maps without an encounter.
- Fight on the arena shown in the preview. Leaving the fight returns your character to the exploration map and position where the encounter began.
- View the detailed **Statistics** tab after combat, including damage, healing, enemies defeated, and action and movement points spent per turn.

## Compatibility

The supported client build is **3.7.14.18**. The starting map at **[0,-3]** uses the arena and placement zones most recently observed in the reference client. This local association is fixed. The other Incarnam maps use the default installed arena until they receive their own catalog entries. Shield statistics reflect the current combat rules.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Existing profiles and characters use the same database schema. The launcher reads the arena from your local game installation.
