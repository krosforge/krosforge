# Krosforge 0.0.6

- Explore all 50 maps on the first outdoor level, with 156 directed connections between neighbouring maps.
- Arrive at the corresponding edge cell when crossing a map boundary, including diagonal exits.
- Read exploration zones separately from combat zones, allowing connected surface terrain and elevation changes.

- Fix characters snapping back or appearing in different positions across local game windows after rapid direction changes.
- Match movement timing to the running profile used by the reference client, preventing valid interruptions from being rejected on longer paths.
- Reconcile interrupted paths and partial reversals while keeping movement updates ordered across local profiles.
- Accept changes to the remaining route during a walk without replaying its origin or triggering repeated position corrections.
- Finish elapsed movements before processing the next action, and prevent stale timers from changing a newer movement.
- Preserve confirmed positions when reconnecting and keep subsequent movement visible to other profiles on the same map.
- Retain recent runtime diagnostics during longer sessions using bounded rotating logs.

## Validation and limitations

The earlier movement correction was validated on Windows in Portuguese with two local profiles, including rapid reversals, longer paths, travel between the previously supported maps and reconnection. Surface testing subsequently exposed a separate route-revision rejection. Regression coverage now includes that recorded request sequence, plus two-account TCP revision, map transition and reconnection. Native visual acceptance of the route-revision correction remains pending. Automated traversal checks cover every surface connection, matching arrivals, persistence and reconnection.

Exploration covers the first outdoor level. Interiors, closed areas and interactive entrances remain unavailable. Mounted movement and multiplayer between computers have not been validated.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Reference client build: `3.7.14.18`. Existing profiles, settings, characters and the shared client copy are preserved; no database migration is required.
