# 0.0.2

Krosforge now supports five launcher languages, opens local client sessions through server selection, and checks for launcher updates from within the application.

## Launcher

- Français, English, Deutsch, Español, and Português, with automatic selection based on the computer's display language and English as the fallback.
- Change languages immediately from the header or return to automatic selection. The choice is saved with your portable data.
- Recover from malformed language preferences, including duplicate JSON keys, instead of preventing the launcher from opening.

## Local sessions

- Use the play action to prepare an isolated client copy for each selected profile, authenticate locally, and open the native server-selection screen on reference build **3.7.14.18**.
- Preparation displays progress and supports cancellation. Canceling stops the remaining selected-profile batch, and incomplete preparation can be retried.
- The original client installation remains unchanged. Each profile uses its own prepared copy and local connection endpoints.
- The selected launcher language is passed to the client, and the local profile name is used for the session identity.
- Keep the launcher open while client windows are active. Shutdown, profile deletion, and update installation are blocked during preparation or active sessions.

## Updates

- Check for newer stable releases from the launcher and confirm installation before downloading and restarting.
- Downloads are checked against the release checksums and expected Windows package contents. Profile data remains in place when the executable is replaced.
- Cancel an update before installation, or recover the previous executable if the new launcher fails to start.
- Recovery retries temporary Windows file locks for up to 30 seconds and verifies the previous executable before restarting it.

## Upgrading from 0.0.1

Version 0.0.1 does not include the update button. Close the launcher, back up the entire launcher folder, download `Krosforge-0.0.2-win-x64-portable.zip`, and replace `Krosforge.exe` with the executable from the ZIP. Keep your existing `Krosforge-data` folder. Subsequent stable releases can be checked and installed from the launcher.

The Windows x64 ZIP still contains only `Krosforge.exe`, with .NET and dependencies bundled. No separate runtime, database service, or installer is required. Game files and credentials are not included.

## Limitations

- Native integration reaches server selection. Character creation, entering the world, gameplay, and multiplayer with friends are not available in this version. Choosing a server does not start a world session.
- Client compatibility is restricted to build **3.7.14.18**. Releases currently target Windows x64.
- A complete client copy is required for each profile, so allow sufficient disk space before preparing multiple profiles.
- Native Unity caches and settings can exist outside `Krosforge-data` and are not included in a launcher-folder backup. Avoid running separate launcher installations with the same profile slots concurrently on one Windows account.
- The executable is not Authenticode-signed. The .NET runtime extracts bundled native libraries to its cache during execution.
