# Krosforge 0.0.8

- Award experience and eligible item drops after victory, using the installed monster grades, experience formulas and prospecting calculation.
- Configure separate experience and drop multipliers through **Configure server**, with translated controls in all five launcher languages. Rates default to 1× and support values from 0 to 100 with up to two decimal places. Zero disables the corresponding reward.
- Apply the drop multiplier to the chance of receiving an item, capped at 100%, without multiplying the quantity of a successful drop.
- Show earned experience and items in the native combat result. Preserve accumulated XP, item quantities and rolled item effects in the local database and inventory.
- Update the running client's displayed level when combat rewards cross a level threshold, without requiring a reconnect.
- Save the outcome, currency, XP and items together. Repeated confirmations and disconnections before the final animation acknowledgement cannot duplicate an award or reroll its items.
- Initialize the energy, prospecting and calendar context required by the native bestiary. Display installed monster attributes, resistances, experience, spells and loot categories.
- Resolve supported multi-target areas, percentage healing and cast cooldowns, and select monster spell ranks from their installed level mappings.

## Validation and limitations

The Windows and Linux verification jobs passed. Native Windows checks used one local account with the Portuguese interface and reference client build **3.7.14.18**. Victories were verified at base and multiplied rates, including a level gain without reconnecting and inventory persistence after restarting the runtime. The bestiary was checked for all 22 species in the six supported surface regions, including the first and fifth grades and the spell and loot panels. Intermediate grades and every individual spell/item tooltip were not exhaustively opened.

The configured starting-map encounter remains the available encounter. Regional monster population is not included in this release. The supported player actions remain the shared unarmed action and two level-one ranged actions for one class; other classes expose the shared action. Equipment use, broader character-stat progression, buffs, summons, tackle and erosion are not implemented. Regular levels use the installed 1–200 thresholds; omega progression is not projected. The detailed participant statistics tab remains unpopulated. Multiple-account combat and other native interface languages still require separate visual acceptance.

Bestiary labels show catalog XP and base/prospecting drop values; earned combat rewards reflect the local server multipliers. Challenge, seasonal and external account bonuses are not reproduced automatically. Unsupported eligible loot conditions fail explicitly. Currency remains the local one-unit-per-victory rule. Reconnecting restores committed rewards, without replaying a result screen.

## Upgrading and data compatibility

Existing profiles, characters, settings and the shared client copy are preserved. The database migrates automatically to **schema 4**, adding progression, item inventory and combat award receipts. A verified database backup is taken before migration. Close all game windows and the launcher before replacing the executable, and keep a backup of your data. Older launchers reject a schema-4 database; downgrading requires restoring a compatible database backup as well as the older executable.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Client catalogs are read from the user's separately installed reference build; no game assets or client binaries are bundled.
