# Krosforge 0.0.6

- Fix characters snapping back or appearing in different positions across local game windows after rapid direction changes.
- Match movement timing to the running profile used by the reference client, preventing valid interruptions from being rejected on longer paths.
- Reconcile interrupted paths and partial reversals while keeping movement updates ordered across local profiles.
- Finish elapsed movements before processing the next action, and prevent stale timers from changing a newer movement.
- Preserve confirmed positions when reconnecting and keep subsequent movement visible to other profiles on the same map.

## Validation and limitations

Validated on Windows in Portuguese with two local profiles, including rapid reversals, longer paths, travel between the configured maps and reconnection. Regression coverage includes the native sequence that previously caused the two windows to disagree.

Exploration covers the two configured maps and their connection. Mounted movement and multiplayer between computers have not been validated.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Reference client build: `3.7.14.18`. Existing profiles, settings, characters and the shared client copy are preserved; no database migration is required.
