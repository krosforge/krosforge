# Krosforge 0.0.4

- Select the local server to connect to the character flow using the reference client build 3.7.14.18.
- Return to server selection and connect again with the same local profile.
- Keep multiple profiles isolated across connection transfers and disconnects.
- Preserve update, deletion and server-configuration protections while a game window remains open, including after a network disconnect.

Profiles receive an empty character list. The native client may open its creation screen automatically. Creating, deleting and entering the world with a character are not supported by this release.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Existing profiles, settings and the shared client copy are preserved; no database migration is required.
