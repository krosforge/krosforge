# Krosforge 0.0.3

- Configure the local server name from the launcher. One classic, multiple-account server is shared by all profiles.
- Apply the chosen name to the prepared client's five supported languages.
- Preserve server settings across launcher restarts and updates.
- Reuse the existing shared client copy when changing the name, with recovery after interrupted personalization.
- Prevent configuration changes while profiles are preparing or running.

## Compatibility

Windows x64; reference client build `3.7.14.18`. The portable ZIP contains `Krosforge.exe`. Keep the existing `Krosforge-data` folder when updating.

This version reaches server selection. World connections and character creation are not available. No client files or extracted game content are distributed.
