# Krosforge 0.0.5

- Prioritize the newly created character in the immediate creation response, so the native client does not select an older character instead.
- Keep the regular character list in a stable order.
- Recover the character list in the same native window after a rejected selection, including creation of the first character.
- Show the character list when entering or reentering the local server instead of automatically selecting a remembered character.
- Update the managed client copy atomically without recopying the whole installation.

## Validation and limitations

World entry and movement are not implemented yet. Native acceptance for this development cycle focuses on Portuguese on Windows; existing launcher languages remain available.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Reference client build: `3.7.14.18`.
