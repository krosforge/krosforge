# Krosforge 0.0.4

- Select the local server to connect to the character flow using the reference client build 3.7.14.18.
- Return to server selection and connect again with the same local profile.
- Keep multiple profiles isolated across connection transfers and disconnects.
- Preserve an already authenticated replacement connection if the previous socket reports a late transfer failure.
- Preserve update, deletion and server-configuration protections while a game window remains open, including after a network disconnect.

- Create and list up to five characters per local profile, with SQLite persistence across restarts.
- Delete owned characters through the client’s confirmation flow, releasing their names and slots.
- Read normal creation appearances from the locally installed reference client; no game catalogs are included in the launcher.
- Generate local name suggestions and show the actual character count at server selection.

Entering the world with a character is not supported by this release.

Windows x64 packages contain one portable `Krosforge.exe` inside a ZIP. Existing profiles, settings and the shared client copy are preserved; no database migration is required.
