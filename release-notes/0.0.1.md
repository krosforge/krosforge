# 0.0.1

First public release of Krosforge for Windows x64.

## Launcher

- Dark interface with a dedicated profile list, installation card, and selection controls for multiple local accounts.
- Original application icon embedded in the executable and displayed in the launcher.
- Create, rename, and delete local profiles. Deletion requires typing the profile name and removes associated records and application-owned copies.
- SQLite persistence, record isolation, and recoverable cleanup of application-owned directories.
- Automatic discovery of the default client installation and manual folder selection, targeting build 3.7.14.18.
- Local runtime started automatically by the launcher, with communication restricted to the current user.

## Distribution

- Portable Windows ZIP containing only `Krosforge.exe`, with .NET and dependencies bundled. No separate .NET installation is required.
- Portable mode is the default. Profiles and the database are saved in `Krosforge-data` alongside the executable, without a marker file. Close the launcher before moving the entire folder.
- Licenses are bundled in the executable and can be exported through the interface.
- Automated builds, tests, ZIP packaging, checksums, and source archives for releases.
- No game client, extracted assets, or credentials are included.

## Limitations

Native integration with client 3.7.14.18 remains incomplete: Play does not open a game session. Character creation in the client, appearance extraction, and multiple native client windows remain pending. Preparation of isolated client copies is available in the runtime layer but is not connected to the interface. Opening the launcher on Windows does not validate game integration.

The executable is not Authenticode-signed. The .NET runtime automatically extracts native libraries to its cache during execution. Existing data is not migrated automatically.
