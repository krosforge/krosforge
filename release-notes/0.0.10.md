# Krosforge 0.0.10

- Earn five characteristic points and five maximum life per level gained. The **Characteristics** panel lets you allocate, redistribute, and reset points for all six primary attributes.
- Restore spent and available points after reconnecting. Existing characters can spend the points earned from their saved level.
- Show the native level-up animation and dialog when you return from a fight that raises your level.
- Open the **Spells** window to inspect class and common spells. Available grades update with the character's level.

## Compatibility

The supported client build is **3.7.14.18**. The spell window displays catalog data. Combat execution remains limited to the supported spell set.

After allocating points, the point balance and HUD update immediately. Reopen the **Characteristics** panel to refresh its attribute rows if it was already open. If a native feature notice covers the level-up dialog, **Esc** closes the dialog.

The local database migrates to schema 5 and takes a verified backup before adding characteristic allocations. To downgrade, use a compatible executable and restore its matching database backup in a separate portable data directory.
